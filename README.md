## 🚀 Project Overview

This project focuses on predicting future stock prices using **LSTM (Long Short-Term Memory)**, a deep learning model designed for time-series forecasting.

The model analyzes historical stock data and identifies patterns to forecast future trends.

---

## 🧠 What is LSTM?

LSTM is a type of Recurrent Neural Network (RNN) that can learn long-term dependencies in sequential data, making it ideal for stock price prediction.

---

## 📊 Features

- 📈 Time-series stock data analysis  
- 🤖 Deep Learning model using LSTM  
- 📉 Data normalization using MinMaxScaler  
- 📊 Visualization of actual vs predicted prices  
- 🔮 Future price forecasting

## ⚙️ How It Works

1. Collect stock data using yFinance  
2. Preprocess and normalize data  
3. Create sequences (past 60 days)  
4. Train LSTM model  
5. Predict future stock prices  
6. Visualize results
